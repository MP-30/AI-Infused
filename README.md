# AI-Infused

This repository is my first step into learning and experimenting with Generative AI and LLM-based applications.

The project currently contains three small projects:

## 1. Basic

In this section, I experimented with different LLM providers and their available models.

* Used **Groq** and **Gemini** to interact with different LLM models.
* Asked basic questions and explored how LLMs respond to different prompts.
* Used the **OpenAI-compatible API syntax** to interact with the models.
* Learned the basics of sending prompts and receiving responses from LLMs.

## 2. Scraper

In this mini project, I experimented with web scraping and using an LLM to process the scraped content.

* Used **BeautifulSoup** to scrape data from websites.
* Used **Gradio** to build a simple user interface.
* Passed the scraped content to an LLM for summarization.
* Learned how scraped data can be combined with LLMs to build a simple AI-powered application.

## 3. Arena

In this mini project, I experimented with comparing responses from different LLMs.

* Compared two LLMs using **Gemini** and **Groq**.
* Used the same questions/prompts to compare their responses.
* Used **Gradio** to build a simple interface for the comparison.
* Explored how different models can produce different responses to the same prompt.

## Learning Goal

The main goal of this repository is to learn the fundamentals of working with LLMs and gradually move toward building more practical AI-powered applications.
